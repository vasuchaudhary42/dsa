How prefix sums really work

  
Ten strategies, one identity: the sum of a[l..r] is P[r + 1] − P[l]. Everything else is choosing what to store about earlier prefixes so that the right one can be found in O(1).

  

    
The identity

    
Let P[0] = 0 and P[i + 1] = P[i] + a[i]. Then P[r + 1] and P[l] both contain a[0..l − 1], which cancels, leaving exactly a[l..r]. This turns any question about a subarray into a question about two prefixes: the one at its end and the one just before its start.

    
Why that is powerful: from pairs of indices to lookups

    
A question such as “how many subarrays sum to k?” has n² candidate pairs (start, end). With prefixes, it becomes “for each end, how many earlier prefixes equal P − k?”, which a hash map answers in O(1). That is the same complement idea as Two Sum, applied to prefixes instead of values. Unlike a sliding window, it needs no monotonicity, so it works with negative numbers.

The difference array is the same identity run backwards
A prefix sum turns values into running totals. A difference array stores changes: +v where an update starts and −v just after it ends. Taking the prefix sum of the changes rebuilds the final values, so each update costs O(1) and one final pass applies them all.

  
Beyond sums
The trick works for any operation that can be undone: XOR (a prefix XOR answers XOR of any range, because x ^ x = 0), products without zeros, counts of a property. It does not work for max or min, which cannot be “subtracted”; those need a sparse table, a segment tree, or a monotonic deque.

  
BugRule

    
Wrong seedCounting: {0: 1}. First index for longest: {0: −1}.

    
Off by oneWith P[0] = 0, the sum of a[l..r] is P[r + 1] − P[l]. Write it down before coding.

    
Negative remaindersJavaScript’s % keeps the sign; normalise with ((p % k) + k) % k.

    
Overwriting first indicesFor longest-subarray questions, store a value’s index only the first time.

    
Inclusive versus exclusive endsDifference arrays subtract at r + 1 for inclusive ranges, at r for exclusive ones.
